# C Under the Hood

A living record of my journey learning C from scratch and understanding what happens beneath the surface of a program.

## About This Repository

I am learning C without using AI to write my code.

Every exercise is written by me through studying, experimenting, making mistakes, debugging, and trying again. AI may help me understand concepts or organize my learning, but it does not generate the code stored here.

This repository is also a small act of rebellion.

In a time when code can be generated instantly, I am choosing to learn the foundations for myself. I want to understand memory, program execution, compilation, and the connection between software and hardware—not simply produce code that appears to work.

## What You Will Find Here

This repository contains exercises, experiments, problem-solving practice, and small projects created throughout my C learning journey.

The contents are not final. I will continue adding new exercises as I learn, revisiting older programs, correcting mistakes, and improving how I structure and document my code.

The repository is organized by broad learning areas:

```text
c-under-the-hood/
├── 01-basics/
├── 02-memory/
├── 03-file-io/
├── 04-command-line/
├── 05-build-systems/
├── 06-projects/
└── 07-leetcode/
```

## My Learning Rules

1. Write the code myself.
2. Understand what each line does.
3. Learn from compiler warnings and runtime errors.
4. Debug the cause instead of copying a solution.
5. Practice concepts through working programs.
6. Revisit and improve older code as my understanding grows.
7. Keep visible evidence of consistent progress.

## Running the Programs

Most exercises can be compiled using GCC:

```bash
gcc program-name.c -o program-name
./program-name
```

For additional compiler feedback:

```bash
gcc -Wall -Wextra -Wpedantic program-name.c -o program-name
```

Some directories may contain their own instructions as the repository develops.

## Where This Is Going

C is the foundation of my path toward embedded systems, microcontrollers, Linux, systems programming, and hardware–software integration.

Over time, this repository will grow from focused exercises into more complete, tested, and documented projects.

## Progress, Not Pretence

The code here represents real learning in progress. Some solutions will be simple, some will be imperfect, and some will later be rewritten.

The purpose is not to pretend that I already know everything.

The purpose is to prove that I am willing to learn it properly.
